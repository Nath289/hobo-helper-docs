Gang Warchamber Helper

The Gang Warchamber Helper modernizes and improves the user experience inside the Gang Warchamber by converting long dropdown lists into searchable interfaces and restyling the warchamber table for better visibility.

Enhanced UI

When you visit the Gang Warchamber, the standard 500+ member select dropdown can be difficult to navigate. The script automatically converts this dropdown into a searchable text box. Simply start typing a hobo's name or ID, and the list will filter dynamically.

Additionally, the Warchamber Table itself is restyled with alternating row colors, improved spacing, and clear hover effects, making it easier to read stats and arrange your fighters using the drag-and-drop handles.

Tip: The drag-and-drop reordering functionality operates exactly as before. Simply grab the handle (⋮⋮) on the far left of any row and pull it into position!
