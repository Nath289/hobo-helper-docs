Message Board Helper

Provides Message Board QoL features like Ctrl+Enter to post, larger vote buttons, latest page quick-links, and the ability to hide specific players.

What does it do?

Provides Message Board QoL features like Ctrl+Enter to post, larger vote buttons, latest page quick-links, and the ability to hide specific players.

How to disable it

If you prefer to disable this functionality, you can easily turn it off:

  • Go to the Preferences page in-game.
  • Scroll down to the Hobo Helper Settings section.
  • Uncheck the relevant box and hit Save.
