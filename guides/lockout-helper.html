Lockout Helper

Displays the most recent Hobo Helper changelog directly over the native 12-hour server lockout screen so you have something to read while waiting.

What does it do?

Displays the most recent Hobo Helper changelog directly over the native 12-hour server lockout screen so you have something to read while waiting.

How to disable it

If you prefer to disable this functionality, you can easily turn it off:

  • Go to the Preferences page in-game.
  • Scroll down to the Hobo Helper Settings section.
  • Uncheck the relevant box and hit Save.
