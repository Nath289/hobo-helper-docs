# Premium Gang Features

The following features and enhancements are exclusive to premium authorized gangs. If your gang is not currently registered for premium access, these specific tools and their respective settings will be hidden.

## 1. Gang Staff Features
- Mass Mail Formatting
- Mass Mail Templates Support
- Current Happenings Dashboard modifications
- General Staff Hub enhancements

## 2. Gang Loans Auto-Filler
- Bulk loan processing for topic repliers
- Auto-fill the game's Loan form directly from saved forum payouts
- Track which payouts have been successfully converted to actual loans

## 3. Gang Board Staff Tools
- Automated Payments UI injected into gang forum boards
- Scraping and processing hobo IDs directly from forum posts

## 4. Gang Hitlist System
- Top Menu Gang Hitlist Quick-Link
- Hitlist Page Tracker
- Hitlist Range highlighting (Auto-mark red within range)
- Top Pagination Links
- Wrapped Pagination

## 5. Personal Hitlist Helper
- Highlight Online Players
- Multi-Column Sorting
- Experience Column

---

> [!NOTE]  
> The basic **Gang Helper** and **Gang Armory Helper** utilities remain fully unlocked and available to all players regardless of gang affiliation.
